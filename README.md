# WeatherNow 🌤️

Aplicação web desenvolvida com **HTML, CSS e JavaScript** que permite consultar as condições climáticas atuais de qualquer cidade utilizando a API da **Open-Meteo**.

## Funcionalidades

* 🔍 Busca de cidades por nome.
* 🌡️ Exibição da temperatura atual.
* 🤒 Sensação térmica.
* 💧 Umidade do ar.
* 💨 Velocidade do vento.
* 🕒 Horário local da cidade pesquisada, calculado a partir das coordenadas geográficas.
* ⚠️ Tratamento de erros para cidades não encontradas ou falhas na requisição.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6+)
* Open-Meteo Geocoding API
* Open-Meteo Weather API
* `tz-lookup` para identificação do fuso horário

## Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de JavaScript, como consumo de APIs REST, programação assíncrona com `async/await`, manipulação do DOM, tratamento de erros e utilização de módulos ES.
